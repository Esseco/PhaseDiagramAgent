# 手动服务控制与配置版本

项目管理页面的“启动服务”和“停止服务”由用户控制。查看状态、选择项目、打开页面、修改配置、更新代码和数据迁移都不启动真实项目服务；代码更新保留服务原有状态，下次用户手动启动时加载。

停止启动中的服务会取消该启动请求，后台启动线程不能在停止后继续拉起。科学流程的审批模式/自动模式与服务启动策略是独立设置。

读取和进入配置编辑不增加草稿编号；只有实际内容修改才增加编号。重复确认相同内容沿用原配置快照。历史模型、配置和审批身份不重新编号，不删除。

聊天和审批页默认只显示项目、轮次、当前模型及实际待确认修改。内部配置哈希、完整模型标识、审批编号保留在详情及机器记录中，继续用于防止跨版本审批和重复执行。
