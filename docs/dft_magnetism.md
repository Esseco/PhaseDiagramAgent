# DFT 磁矩回收与限制

回收仍保留所有原子的最终帧磁矩及原子顺序，不因磁矩异常丢弃原始结果。
`science/dft/magnetic_constraints.py` 独立管理各元素磁矩范围及层状 Fe/Mn 氧化物的高自旋默认范围；`magnetic_diagnostics.py` 验证证据和缓存；`spin_acceptance.py` 管理科学数据资格。

默认逐原子检查绝对值：Fe [3.5, 4.5]、Mn [3.0, 4.0] μB，含端点，允许负的共线磁矩。可在 manager 的 `system_config` 中添加：

```json
{"dft_magnetic_abs_ranges": {"Fe": [3.5, 4.5], "Mn": [3.0, 4.0], "Co": [1.5, 2.5], "Ni": [0.5, 2.0], "O": [0.0, 0.2]}}
```

支持任意合法元素符号，也允许只设置一个元素。示例中的 Co/Ni/O 数值仅演示配置，不是推荐科学标准。显式设置的范围适用于含该元素的任意相；未显式设置的 Fe/Mn 默认范围仍仅用于层状氧化物。所有其他元素不设默认范围，磁矩照常保留并在 CSV 中标为 not_checked。无效范围或缺失磁矩为 unknown，不能视为通过。限制参与证据哈希，修改限制后再次分析会重新检查。旧已保存产品需重新分析后更新，不自动改写历史项目。
超限原始数据保留，但未通过科学检查的任务不进入相图、微调和误差配对。该经验范围不是磁基态证明；非共线数据仍不通过本高自旋检查。

每轮导出 `diagnostics/magnetic_moments.csv`，并由独立 `analysis/feedback/dft_magnetic_plots.py` 在 `diagnostics/magnetic_plots/` 绘制每种过渡金属的绝对磁矩直方图，包含正常与异常结果，标注该轮实际允许范围。非共线向量单独绘制模长且不据此放宽科学资格。缺失、无穷及非法值不填零，记录排除数量；没有有效磁矩则明确报告 unavailable。输出索引列出各图。不会重跑 DFT 或启动项目服务。
