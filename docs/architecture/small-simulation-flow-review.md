# 小范围咨询与 Simulation 流程简化

本轮基于当前磁盘源码与近期审查，不以 Git HEAD 作为前态，不触及真实项目或运行服务。未派生开发子 agent、切换模型、调用科研模型、部署或操作 HPC。

## 核实与边界

原有 ConsultationPlan 已支持零/一/两位专家和角色子问题；无需新路由。普通图仅对 DIRECT 缺口补 Reliability，最终动作没有统一必要角色兜底。原生草案多数必须提交模型文字计划；普通支持 Simulation 的客户端也逐案生成计划。已知工具阻塞还会请求模型解释。

现在共享 necessary_roles/missing_role_reasons，复用操作、科学决策点、结构化研究路线、外推风险及现有快照。它只是必要条件，不替代主 agent 的语义判断，不按自然语言关键词选动作，不新增模型调用。未知工具/处理模式保守要求两位专家。范围不明确的已知探索/可靠性操作仍保留其责任专家，Simulation 不擅自判为成熟。

| 新决策/处理 | 最低分工 |
| --- | --- |
| 新分支、MC分配、探索输入范围 | Exploration |
| DFT选点、模型更新、外推恢复与未证实固定的训练/DFT输入范围 | Reliability |
| 收敛、结构化跨领域路线、未知操作 | 两者 |
| 明确已登记的待办DFT任务输入清单 | Simulation程序检查 |
| 查询、恢复原冻结方案 | 不新增专家或Simulation模型调用 |
| 其余执行组合 | 保留原Simulation模型计划/能力阻塞 |

主 agent 仍可增加必要咨询。意见必须匹配本轮 snapshot；既有 revision/source 校验不变。insufficient_evidence 不能满足必要角色；沿用原有一次澄清或修订，不增加自动循环。专家可用可选 handoff_roles 请求跨领域审查，不授予对方权限。旧意见新增字段默认空，历史格式仍可读取。

原生 draft 缺角色时返回 missing_roles/原因及自包含专家请求，保持 consulting、不保存可执行草案；普通新方案则明确校验失败，保留失败证据。旧 callable 接口保留，但新科学选择缺能力不能冒充咨询完成。原生/冻结适配器不回退调用项目模型。

## 最小程序协议

仅覆盖 prepare_local_batch_files + parameters恰为 {mode: dft_inputs} + 非空明确target_ids。所有目标须唯一登记、pending、DFT阶段、未登记提交批次、模型身份已知，当前配置/模型版本已知。沿原消费者定义检查；重复或缺失任务、未知版本直接阻断，不能让模型声明成熟。

普通摘要只补充这一判断所需的待办任务身份；完整任务不复制给每个角色。Simulation 从实际状态重新验证，以注册任务全文摘要、配置/模型版本和最终动作哈希冻结 _simulation_program。原生还保留讨论来源绑定及原始意图；最终参数新增/变动、任务内容/状态或版本变化会使记录失效。无跨版本意见复用或新持久缓存。

程序记录明确 handler=program、实际预检项目、未满足条件、授权仍待原审批；不伪造 SimulationPlan 或专家分析。输入文件/HPC检查未执行时仍为 not_executed，科学完成未知。后续文件准备、资源/预算/审批校验、工具调用、验收及回执仍在唯一 actions 图。拒绝审批不执行；重复批准不重放。

原 _simulation_plan 优先，原冻结方案不补咨询、不补模型、不迁移或重新批准。原生暂停/只读收敛评估的既有模型计划豁免保留；科学收敛判断本身仍要求两位专家。明确reason/validation_errors的已知工具阻塞不额外请求解释模型；异常或未知失败仍可返回真实诊断请求，绝不自动重试。现代客户端缺 Simulation 能力时明确阻断复杂计划。

## 未扩大范围

没有把所有固定处理统一成分类系统；Relax–MC、训练交接、结果恢复与其他组合暂保守走原契约，后续只有真实依赖闭合且有收益再扩展。自由文本中的隐含跨领域目标仍由主agent语义判断；程序只兜底结构化事实，不声称完全识别自然语言科学意图。未改阈值、采样、审批偏好、记忆、调度或状态强校验；只新增兼容的程序元数据，不迁移已有持久记录。已完成的上下文与缓存优化保留。以上仅是磁盘源码修改，运行服务版本未核验、未重启或部署。
