# 精确候选弛豫的无变化反馈复用

项目入口仍先执行已登记结果收集、恢复和回执协调。只有 Codex 已核验的精确候选弛豫提案，或同一冻结方案的批准/拒绝，且未产生新回传、后台训练或其他回收变化时，才尝试复用。模型、配置、凸包和授权范围必须一致，逐项校验候选原文件；任何不明状态、待处理任务、历史错误、执行回执或未诊断 DFT 失败均退回原流程。

历史相记录需与原任务、能量、规则和最终结构内容绑定；不完整、未知或规则范围无法验证的旧记录、弛豫质量异常及现有报告校验失败时，执行原科学反馈。已有 DFT 报告复用直接调用现有导出器的只读复用校验，比较原始输入版本和已发布文件哈希；有缺失或变化则重新生成。未完成同帧比较时仍执行原比较与导出。收敛周期和状态保存仍正常运行。

检查点记录本轮回收是否更新及复用结果；旧检查点缺字段时保守回退。该优化不覆盖任意科学提案，未验证的历史证据或自定义结果收集器保持原流程，不保证所有项目都能命中。大项目真实内存和部署效果尚未验证。

已冻结精确弛豫只准备本地输入。若回收未发现变化，范围外记录与明确的分类器无匹配结果可以保持原状，但须同时验证最近的结构摘要、便携规则指纹和原任务绑定。缺文件、解析错误或规则不匹配仍进入完整反馈。节点日志只记录首个回退原因或复用成功，不附带科研数据。
