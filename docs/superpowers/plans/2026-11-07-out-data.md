# Out Data Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a reusable analysis exporter that writes analysis_outputs/out_data/DFT_err_data.csv plus one epochN_structs_features.csv per model epoch, then invoke it through the existing analysis refresh path.

**Architecture:** Build a pure, read-only exporter in phase_agent/analysis/feedback/out_data.py. Reuse summarize_model_rounds for per-model DFT feedback metrics and training_result_evidence for returned K-fold reports. Build structure rows from verified Relax/MC task outputs, phase-diagram entries, QBC fields, and available M3GNet/D-H fields without recomputing missing scientific data. Call the exporter from publish_output_catalog so existing phase_plot(refresh_analysis=True) refreshes the files.

**Tech Stack:** Python 3, csv/json/pathlib, existing phase_agent evidence and analysis modules.

## Global Constraints
- Do not mutate scientific state or recompute DFT/MLIP/M3GNet results.
- Preserve existing output products and tolerate missing historical fields.
- Use stable, non-duplicated structure names within each epoch file.
- Emit explicit blank/unknown values for unavailable features rather than fabricate values.
- Keep existing dirty-worktree changes intact.

### Task 1: Implement pure out_data exporter
- Create phase_agent/analysis/feedback/out_data.py.
- Add tests in tests/test_out_data.py.
- Export model-round DFT feedback metrics, returned K-fold total/fold/current-round metrics when files are available, and explicit status/source fields.
- Export Relax/MC task rows with composition, phase, Na content, Ehull, energy/atom, QBC, source, feature payload, and optional D/H final feature difference.
- Deduplicate deterministically and write CSVs atomically through temporary files.

### Task 2: Integrate exporter into analysis refresh
- Modify phase_agent/analysis/feedback/export_dft_products.py.
- Invoke export after existing publication products are refreshed.
- Keep exporter failures isolated from scientific publication status and expose output paths where appropriate.

### Task 3: Verify and refresh projects
- Run focused out_data/publication tests under py1.
- Use the existing Agent analysis refresh entry for each configured project.
- Inspect generated files and report missing fields without fabricating data.
