# 安全恢复与记忆后续范围

已接入：严格身份、公共工具收据、生命周期恢复清单与派发阻断；相关词与预算检索、替代/模型条件过滤、检索原因进入决策上下文。

尚需逐步完成，不宣称全量自动续跑：

1. 将生命周期业务进度迁出调用期frame，定义各节点可序列化输入、产物清单及配置/模型/数据指纹。
2. 回收/导出等节点按产物指纹对账，补齐未完成写入；提交、删除、激活不确定时保留人工确认。
3. 动作明确返回的任务已关联决策、原模型、状态和实际成本；人工批准替代会保留旧记录并停用。仍需完善批次收益与预期的显式关联、重新验证，以及无返回任务ID的历史动作迁移；禁止猜测因果或自动变成授权。
4. 构建记忆命中/遗漏和重启故障案例；评估是否再接Deep Agents上下文管理，暂不引入第二套执行器。

当前改动不处理生产数据、不提交计算。避免在旧state/ledger上未经迁移直接启用全流程检查点。
