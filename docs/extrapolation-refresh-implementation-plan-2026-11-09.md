# 外推刷新恢复计划

目标：仅在新 epoch 刷新后按已确认规则评估外推，并限制每 epoch 补充次数；外推模块不负责 DFT 执行或失败处理。

复用：现有弛豫监测、刷新轮次证据、DIRECT 与母帧微扰流程、DFT 台账与训练交接、相图隔离和已有权限审批。

拟修改：外推证据及可靠性模块、刷新与决策门槛、恢复状态和采样交接、产物命名、相关测试及指南；具体文件随调用链审计确定。

状态接口：按模型 epoch 绑定刷新证据、采样类型和最多五次补充；读取 DFT 结果中经核验的合格去重标签数量，但不执行 DFT 或处理失败。超过30条结束补充并进入现有训练交接。历史状态保持可读。

风险：刷新与正常 Relax-MC 的门槛需要一致；重启不得重复计数；未完成任务及迟到结果不得当成功；初始无旧凸包时需明确母帧来源；更改不得放松科学与授权校验。

验证：py1 环境使用临时合成数据检查阈值边界、未知证据、5次上限、切换、31条标签与恢复幂等，执行相关回归；不启动真实科研任务。
