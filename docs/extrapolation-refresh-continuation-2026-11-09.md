# 实施计划：epoch 刷新外推恢复

目标：Relax–MC 保留外推计算及普通 DFT 采点证据；仅 epoch 刷新触发外推补充。DFT 管理保持既有边界。

复用现有弛豫监测、DFT 结果台账、DIRECT、母帧微扰、模型刷新、授权与恢复链。

工作：1. 改刷新触发边界并验证 MC 证据与普通 DFT 候选；2. 集中实现 epoch/比例采样策略；3. 持久记录最多5次、跨批去重的合格标签及切换；4. 保持旧状态恢复、模型激活校验和原审批；5. 组织可识别文件与文档。

风险：每次恢复的不可变回执目前按单 scope 存储；多批不得覆盖身份、丢弃成功数据或自动重试；原 DFT 失败审查与新流程必须正确衔接；无旧凸包的初始轮应单独处理，不假设成功。

验证：py1 临时目录合成测试阈值边界、恢复幂等、累计31、上限5、MC仅证据、旧状态及真实训练范围；不操作真实项目。
