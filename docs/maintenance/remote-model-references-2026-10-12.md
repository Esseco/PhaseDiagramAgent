# 远端模型引用修复与验证

本地只保存并序列化远端模型路径；不要求模型文件存在，不下载或打包权重。单模型支持 remote_model_path，委员会支持 remote_model_paths、model_paths 或成员的远端引用。旧登记兼容。重复/空路径、成员数量不匹配、主模型索引越界在本地直接报告配置错误。

Co、Cr、FeMn 当前登记均已核对，保留原模型版本和路径，不重写确认配置、审批或历史任务。FeMn 由成员登记生成四个远端权重引用。三项目均在临时目录成功生成 Relax+MC 输入及完整 inputs.zip；禁止 .model 的本地文件探测，压缩包不含权重，禁止执行计算。生产 state.json 和 phase_data.json 字节未变。

远端 dispatcher 执行前检查权重和已记录的身份。错误保存于 return-results/dispatch-error.json 和 .submitted_jobs.json，并明确指出是超算路径问题、本地无需下载；失败前不提交任何新子任务。真实超算路径是否存在或模型能否加载未验证。

历史 FeMn 失败记录保留；本地无权重能力不会自动修复已经发生的远端文件缺失。核对真实远端路径后，按原审批机制提出失败任务重试方案，不重新分配预算、不重交完成任务。

当前服务没有启动、停止或重启；需用户手动重启本地 Agent 加载源码。新生成输入包包含更新 dispatcher；旧压缩包内容不改。验证输入包属于测试任务，不得上传提交。

- O3-1ele-NaCoO2: 1 个远端引用，Relax/MC 压缩输入通过。
- O3-1ele-NaCrO2: 1 个远端引用，Relax/MC 压缩输入通过。
- O3-2ele-NaFeMn: 4 个远端引用，Relax/MC 压缩输入通过。
