# Branch 区域优先改造（2026-10-15）

范围只包括 branch 生成、待审区域方案与实际统计；不运行 FeMn 的结构生成、Relax、MC、DFT，不准备或提交计算输入，不管理真实服务。

## 决策与程序边界

- 新在线提案采用 `region-adaptive-branch-v2`。Agent 读取当前账本统计、有效模型证据及已有记忆，选择明确的相、H 倍数范围、Na/O2 范围、策略、优先级和依据。未知收益只能作为探索假设。
- 禁止科学方案中的 quota、quotas、total_quota、batch_size、generation_plan。没有固定 600、96 或最低100；旧v1记录仍可读取，迁移为v2的项目拒绝执行旧配额方案。
- 审批前仅做母胞元数据合法性预览，不扩胞、不初始化。冻结配置、模型与账本指纹；发生变化要求重新审阅。
- 审批后复用现有策略注册表、最终去重、初始化及登记。内部每批16次只是工作块；优先级排序后逐区域轮流尝试，连续3批无新覆盖/新初始TM近邻相关性描述符则结束该区域。
- 便宜描述符使用同一相/H/x内最近TM对的元素配对直方图，距离阈值为最近距离的1.1倍、频率按0.1量化。描述符不等于能量或物理收敛；随机连续停滞不证明空间穷尽。
- 尝试4096次、候选新branch1000个或300秒触发暂停审阅，都是保护阈值，不是目标或最终科学截断。时间在批次边界检查，不保证昂贵单批可被中断。最终初始化时间不计入候选采样保护时间。
- 最终JSON按实际登记统计新增branch、结构及相/H/Na分布；初始化失败和最终去重可能进一步减少数量，不凑数。只生成登记，不调用后续输入封装。
- 新文件使用独立 `branch_region_plan_*.json`，已完成清单不能被方案刷新覆盖。DeepSeek失败不会在在线路径回退到旧配额生成。
