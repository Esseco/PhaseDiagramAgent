## 当前分层的真实含义

| 调用用途 | 思考模式 | 证据读取 |
|---|---|---|
| 初次定范围/取证 | 关闭 | 阶段事实、证据索引、用户问题 |
| 状态核对、已确定范围的输入整理 | routine，关闭 | 必要字段；涉及科学选择则回到科学层 |
| 已有证据上的有限科学比较 | 开启，默认 low | 完整相关候选及原有前置证据 |
| 具体冲突、方法选择、新假设 | 开启，由模型选 high/max | 按需扩展；不限制跨路线取证 |

这是同一 Agent 的调用策略分层。记忆读取依主题/字段和前置条件决定，不按层硬截断科学证据；执行快照默认索引，必要时可完整读取。routine_max_tokens 与 reasoning_max_tokens 是不同基线；候选级结构化输出沿用原有动态扩容，不把 low 的最大输出长度硬压成几百 token。思考 effort 与最终 JSON 容量是两个参数，不能混为一谈。

API 参数依据官方文档：https://api-docs.deepseek.com/guides/thinking_mode/ 。low 仍开启思考；模型自主升级不改变工具权限。
