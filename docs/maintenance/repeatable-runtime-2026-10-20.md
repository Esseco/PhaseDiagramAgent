# 可重复运行改进与验收（2026-10-20）

本轮沿现有 LangGraph 主干完善可靠性，没有增加第二套调度或项目状态。日常入口仍为 `python -m phase_agent.runtime.local_project_launcher`；离线检查与人工恢复见 [检查与恢复](../guides/recovery.md)。

## 已完成的改动

- 配置验证提前检查对象、列表、数值和整数约束；坏类型、NaN/Infinity、分数计数返回字段问题，不在类型转换处崩溃。运行时 JSON 兼容 UTF-8 BOM，语法错误包含文件和行列。
- 回收边界按任务隔离文件占用/读取错误、坏快照和清单；正常结果仍可核验，修复后可重新读取原任务。结果解析和 checksum 使用同一份字节，未改变身份、版本或科学入账门槛。
- 可选节点日志写入失败不掩盖业务错误、不推翻已完成操作。统一 Windows SQLite 只读 URI，支持长路径拼写、中文、空格、`%`、`#`。
- 新增 `project_diagnostics --runtime`：配置、实际存储路径、状态、台账、母结构、版本、回执分别检查；草稿尚无状态与已确认项目缺状态明确区分。历史反馈错误增加当前格式复验统计，不据此修改科学结果。
- 补齐待审方案下的配置查看图路由；普通答疑减少重复状态。审批引用不匹配返回明确恢复提示。MC 重生成的重启审批交回原维护节点；输入变化仍须重新确认。精简审批卡也保留本轮已核对的回传事实。
- 会话坏行跳过、独立临时文件原子写入、锁内写入对应轮次；最近回复仅送一份，同轮配置会话只读一次，Studio 缓存限制 32 个。已批准知识以 ID 索引处理替代关系，保留体系、项目、模型和适用条件限制。
- 会话存取统一归入 `phase_agent/persistence/memory/conversation.py`，与长期知识同属记忆模块；原图目录实现删除。公共脱敏独立到 `phase_agent/text_safety.py`，记忆存取不再反向依赖运行时。迁移函数 AST 保持一致，现有记忆文件路径与格式兼容；缓存淘汰后仍能恢复持久会话。
- 正式入口、恢复指南和模块扩展表已整理。27 个原有格式不一致的 Python 文件只调整格式，AST 与原文件一致。
