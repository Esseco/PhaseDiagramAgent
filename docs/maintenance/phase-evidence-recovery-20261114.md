# 已回收单点相别证据恢复

目标：对已回收刷新结果安全补登可复核的单点相别，保留原始结果与回执；未来缺少可复用证据时直接按最终结构识别。对不能识别的结构仅按明确指令排除，防止失效新结果对应的旧模型点进入凸包。
复用：phase_analysis_wave、identify_result_phase、verify_result、项目生命周期锁、结果验证与相图重建入口；采用 py1，不调用模型或提交计算。
拟改：远端相别分析与其合成测试；新增具备身份/哈希/并发检查、可审计和幂等性的已回收相别恢复入口及针对性测试，并接入 Codex/Agent 入口。
风险：篡改原结果、漂移的任务/模型/相别范围、并发写入、混用旧模型导致错误凸包；必须只追加证据、严格拒绝绑定不符，先合成测试，再经正式项目入口执行用户授权的范围。
验证：36 条识别与两条未知的合成案例、身份和结构校验失败、重复执行、旧点排除及凸包；运行相应测试和 ruff，真实业务处理只通过项目 Agent 入口。

## 完成情况

- 缺少可复用单点相别证据时，核对输入与最终结构哈希并重新识别；已回收结果通过原任务回执、冻结相别规则、结构校验及项目事务补登，保留旧证据。
- 对明确授权的未知相记录保留原始结果并排除；排除新刷新记录时禁止其对应旧输入帧重新进入最新谱系凸包。
- 支持用户明确指定当前模型作为本轮凸包唯一能量来源，并通过按需状态投影发布当前图件。
- 合成测试覆盖回执与结构冲突、未知相授权、来源过滤、真实事务提交及安全重放；相关测试 59 项通过。
- 仓库级格式检查仍有大量既有未格式化文件，未批量改写；另有一项旧 DIRECT 测试与现行先扰动恢复规则冲突。
