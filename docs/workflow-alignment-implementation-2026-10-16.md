## 最终运行规则

1. 正式相图、当前摘要、搜索收益和停止趋势只使用当前 MLIP。DFT 用于同帧误差检验、关键排序检验和累计微调。回收主路径不再刷新 combined/DFT 凸包；历史诊断文件与状态引用保留，旧底层构图 API 保持兼容。
2. 新生成方案复用已有 100–1000 branch 数量策略及原生成器，要求明确分配、范围与数量一致；优先小超胞，再比较扩大搜索的收益和成本，不强制穷举。合法空间和去重导致不足时沿用实际登记数。生成后停止，下一步封装另审；不对封装内部三段 MC 再逐段审批。
3. 首轮 DFT 达到现有有效数据要求后，下一科学提案须为首次微调；不足时不降低分组或样本要求。后续比较新增 branch 和补 DFT 的收益/成本；DFT 完整回收后比较探索、微调、收敛。正常训练成功后按固定路线申请模型切换，不再请求一次模型选择。产物无效或训练失败保留原模型。
4. 训练准备、自定义训练适配器和激活都要求真实活动任务结束。等待豁免不等于任务结束。模型切换后沿用现有结构刷新与相图更新流程。
5. 完整反馈周期要求同模型的新 MC 搜索和明确关联的成功 DFT 批次；整批回收，不能重复计数，也不能拿历史 DFT 拼接新搜索。旧记录若缺少来源关联，不推断为新收敛证据。每次完整搜索消耗本轮全部新搜索；同一搜索只补第二批 DFT 不另算一轮完整搜索。
6. 交付要求一轮完整反馈稳定、稳定结构集合不变、当前 MLIP 稳定结构严格超过 60% 有同几何合格 DFT；当前模型未训练的新 DFT 能量 MAE 严格小于 0.005 eV/atom、力分量 RMSE 严格小于 0.05 eV/Å；关键同帧排序一致，报告覆盖与风险，最后由用户接受。相图变化容差沿用已确认值（模板仍为 0.003 eV/atom）。
7. 每次新 DFT 选择复用独立随机抽查并至少保留一个抽查点；单点默认。Relax 需近凸包影响与同几何 DFT 残余力超过原 Relax 目标的实际证据；QBC 高不能单独证明需要 Relax。通过源任务、原子顺序和几何身份核对证据。
8. 建议模式下不按参考成本、余额、每轮或累计数量截断 DFT 候选。成本账本、物理限制、已批准批次和资源范围继续有效。历史明确硬约束的低层兼容 API 保留，生产新模板使用 advisory。
9. DFT 共享默认关闭，只导入用户明确指定项目的合格标签，复用 TM/协议/边界检查；不共享模型或任务。新提案冻结来源、记录 ID 和指纹；批准执行只接受同一快照。期间新进入共享库的记录留到下一次提案/审批，不改原方案。
10. 人为修改超胞上限使用已有配置版本机制；支持实际 UI 的 `system.H_generation.size_max`、显式 H 与对应 determinant 上限。活动任务和待审批方案结束前保持旧配置，随后生效；不改旧任务或输入。
11. 供应商响应失败、结构化输出失败直接报告，不静默自动重试、重发修复或用规则替代科学决策。一次调用的 token/未知用量仍记录。保留按需取证、短记忆、缓存和经验批准发布。DFT 失败超过 50% 形成提示，结合数量及既有共同错误事实交用户判断，不自动重提。

## 保留兼容的裁定与代价

- 新提案采用仓内已有 100–1000 策略，旧冻结区域/封装审批不重写。代价：旧方案仍按原展示范围执行，不自动变成新方案。
- 旧训练方向提案不因新政策静默替换；新训练完成才走固定切换路线。代价：历史已展示方向仍需按原身份处理。
- 不自行收紧或放宽已确认 hull 容差；交付误差采用明确的 5/50。代价：个别旧项目仍需用户核对其原始科学容差。
- 旧训练模型缺少完整训练身份时不承认新误差样本独立；不猜历史训练集。代价：可能需要补齐真实训练来源后才能满足独立交付条件。
- 每轮全部新 MC 搜索与其后的已关联 DFT 合为一轮完整反馈；同批搜索再补 DFT 不加轮数。代价：计数更保守，但不会用重复补算冒充新探索。
- 底层旧调用未携带新反馈规则时保留兼容模式；实际生产 handler 注入新规则。不能把旧 API 的模型 epoch 当新流程收敛证据。
