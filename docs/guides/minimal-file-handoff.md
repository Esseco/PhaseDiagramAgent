# 必要文件传输

Relax、MC、DFT 和微调采用同一套传输清单。手工任务准备生成相邻的 `<批次>.upload.zip`（微调为 `inputs.upload.zip`）；上传并解压到对应远端 inputs 目录，保留原目录层级。按原 GPU.sh 提交规则执行，不改变审批或计算策略。

新版远端脚本生成 `<批次>.results.zip`；只下载这些包到登记的本地 results 目录，回复“继续”。代码验证传输清单及 SHA256、自动展开，再由原科学回收器验证任务身份、完成标记和科学数据。回传包不会替代任务完成证据。导入记录保存于 results/.transfer_receipts；冲突文件不覆盖，错误在回收报告展示。

输入包不含本地说明、日志、缓存和已有 results；必需运行脚本、输入结构、训练数据和续跑检查点保留。结果包只含回收必需的结果 JSON、完成标记、最终结构、DFT 训练帧/同帧预测以及 MC 检查点。微调仅回传五个指标/模型清单文件。模型二进制、计算大日志和轨迹留在超算，原 remote_artifacts.json/models.json 记录路径、大小和校验信息。

旧已准备/运行批次仍可回传原精简 results 文件夹，不重新生成任务或改写冻结输入。相邻输入包可从原输入目录补建，不需迁移历史 state。远端科学运行环境仍需安装原项目和科学依赖；新手工输入包自带更新后的打包适配代码。SSH 传输按必要文件清单筛选，不递归下载整个结果目录；旧 task-local 回收继续支持。

导入仅查看登记的 results 目录，不猜其他项目或扫描磁盘；压缩包的文件数、解压总大小、路径和校验信息有检查。不同内容的同名结果需明确处理，程序不会静默覆盖。科学输入、原结果和模型不会因打包而删除。
