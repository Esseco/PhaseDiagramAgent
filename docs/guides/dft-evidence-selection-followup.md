# DFT decision evidence follow-up

The decision evidence and Codex rule audit no longer supply a fixed weighted candidate ranking. The strategic Agent must choose the count and candidate decisions from current bound GS, Ehull, available QBC, D/H, coverage and extrapolation evidence. Existing independent audit IDs are retained and the DIRECT exemption is unchanged.

The change does not implement a new automatic decision generator and does not waive exact-frame monitoring. An unknown monitor is not normal, and a final-frame monitor result cannot be assigned to a different input geometry. Where required GS frames lack evidence, a compliant DFT selection is blocked until a scientifically valid, frame-bound evidence path is available and the usual approvals are respected.

Regression: the existing synthetic perturbation integration test conflicts with the current parent-first recovery requirement (`new_recovery_requires_parent_first_perturbation`); this unrelated fixture requires reconciliation against the current recovery contract.

New DFT previews enforce selection of all eligible unvalidated GS and bind the all_eligible_gs_v1 policy to the approved preview. Execution rechecks the marked policy. Older frozen proposals retain their historical validation contract, and exact DIRECT scopes retain their existing exemption.
