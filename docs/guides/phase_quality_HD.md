# 简化H/D相图审查

只调两个参数，单位meV/O₂：**H阈值默认50，D阈值默认50**。当前单结构H>100直接移除，但端点基准保护优先。

H是移除后的凸包最大抬升；D是同相同组分低能结构与上方参考的能量断层。两者不相加。凸包附近的D离群点即使H较小也需要审查。

D的统计池严格限定为当前同一模型、同一能量方法、完全相同的归一化组分（包括Na/O₂和TM/O₂）、同一最终识别相。记录按精确几何去重，不能混用邻近Na含量、其他相或其他模型，也不按记录重复数放大证据。使用已保存能量，单位meV/O₂；同组分下端点归一化的线性参考会抵消。

具体定义：按既有10 meV/O₂组跨度形成低能前缀L，优先全部成员均近凸包的前缀。R是该统计池中L以外最低能起50 meV/O₂内的上方参考。`D = min(E_R) - max(E_L)`，是簇间最近边缘的保守间隔，簇内成员共用一个D，避免重复计分；当前阈值严格D>50。参考中位数间隔`median(E_R)-max(E_L)`和参考跨度、几何数同时保留辅助解释，不另拟合高斯分布或当作误差概率。无参考时D未知；少于5个去重几何时标参考不足，D数值本身不证明能量错误。

例如L=[-300,-295,-290]、R=[-210,-205,-200]时，D=80，参考中位数间隔85 meV/O₂。D是分布断层，不是最低结构必然错80，也不能用来直接修正预测能量。

|条件|结果|
|---|---|
|端点同相基准簇缺少独立替代参考|保留并标注待验证或补算，优先于自动规则；右图也保留|
|当前单结构H>100|自动移除|
|H或D超阈值，且现有公共结构模块确认有问题|自动移除|
|其余H或D证据较高，或影响未知|人工审查；正式保留|
|其余|保留|

结构检查直接复用`Process_AL_MC.structure_check`及能量/初末文件绑定适配器，不另造判据。证据不足不视为结构正常，也不作为自动删除依据。

每个“Na含量＋相”只出一条审查项，相近结构放在一起，不展开嵌套分组。内部保留能量组跨度10、上方参考窗口50、最多五项联合检查；这些不作为日常调参项。参考不足明确标注。整项联合H不能冒充单结构H>100；只有假设排除上游结构后才出现的高H/D不授权正式删除。

左图为当前正式集合；右图沿同一条排除链，在被排除结构的位置打×并区分档位。两图分别使用各自保留集合的端点归一化，共用纵轴范围和能量单位；每张图所有相共用同一端点连线，×也减去右图端点连线。H仍按固定原始能量参考计算，不能直接读作两图纵向差；D、同一集合内的Ehull和GS不受线性参考变换影响。第二档在正式数据中保留。端点保护、人工保留和人工恢复会约束假设排除，不能把各层所有标记取并集绘图。

`endpoint_reference.endpoint_relative_energies`复用现有形成能计算口径及NumPy线性插值，供`build_composition_hull_entries`、普通相图、对照图和×共用；输入直接来自已保存能量，不另造示例或替代数据。绘图规则版本独立于诊断规则版本，更新旧图片/轮次收据不会改变H/D证据或人工审查身份。

递归按H/D截止参数继续，到没有新增合格集合后再以剩余集合复核一次。默认`recursive_max_layers=None`，每轮至少减少一个精确几何，因此用初始几何数加一作为内部终止保护；不会固定在三次后停。显式设置正整数仅用于诊断限深，未收敛须标注`recursive_truncated`。自动实际处置同样按当前证据重复到无候选，并防止重复排除；条件证据不能触发正式删除。

端点同相替代要求：最低能基准簇（跨度10）之外，移除后仍有至少5个精确几何落在跨度50内的同相同组分能带。基准簇里的近重复点、其他相均不计作替代参考；5/50沿用内部参考要求，不增加用户参数。参考足够也不代表物理正确。整个联合集合必须满足端点约束，不能拆开不成立的集合执行。正式删除入口与预览入口均复核这一条件，防止逐轮耗尽同相参考。

DFT选点主要参考第二档D，H补充相图重要性，再结合Ehull、QBC和预算。每个低能簇与上方参考各选代表；不把嵌套证据重复计分，不自动增加名额或提交计算。

优先检查当前near-hull；近凸包范围沿用本模块的H审查窗口（默认50 meV/O₂），不新增用户参数。当前远离凸包的结构即使D大，也不给本模块的额外选点优先级；每次递归后重算距离，进入该层近凸包才激活条件证据。联合集合中含远点时不提前整组移除；优先较小的近凸包低能前缀，随后再复核暴露点。这个审查窗口与DFT现有`near_hull_threshold`（eV/atom）用途和单位不同，不能混用。

DFT的`predicted_Ehull`始终来自**当前正式保留集合**：自动/人工确认移除后，用新正式凸包重算并重建候选缓存；仅人工待审的假设右图不替换正式Ehull。`post_mc_candidates`已经从当前快照读取Ehull及版本；候选指标保留该版本与单位。递归距离为meV/O₂的诊断证据，携带前序移除条件，只用于补充核查/探索点建议，不冒充eV/atom的正式Ehull。D不加到、减去或替代Ehull，不自动重分配DFT名额；QBC继续走原预算、去重和审批流程。

选点解释顺序：Ehull说明当前相稳定性相关性，H说明相图影响，D说明同相同组分分布分离，QBC说明模型间分歧。近凸包且D大的簇应优先提出成对验证建议：低能簇代表、上方参考簇代表，必要时补充递归后暴露的竞争结构；QBC低也不能排除共同偏差。D小但QBC大则按原有不确定性/覆盖策略选择。参考窄且充分时D证据较明确；多峰、稀少或宽分布应标不确定，不用简单加权总分伪造确定性。所有建议仍受现有DFT预算、重复检查和审批限制。

## 调整阈值

直接说“把H阈值改成60，D改成75 meV/O₂”，或授权agent依据数据调整。agent通过现有LLM语义理解，不用关键词匹配；人工指定值优先，明确交回agent后才解除对应固定。程序内部保存前后值、原因、来源和版本，无需用户管理编号；本轮调整参数不同时执行删除或计算。数值须有限、>0，H审查值不得超过固定直接移除值100。

程序入口`phase_quality_policy.update_quality_policy`，持久化用`commit_quality_policy`，复用现有锁和状态/ledger事务。`state.phase_quality_policy`保存设置及审计；有效阈值绑定报告缓存和审查身份，旧报告不能用于新阈值下的删除。

## 删除与恢复

只移除选中的活动结构及其有效记录，进入独立可恢复归档；branch及其他成员保留。同一结构仍被其他有效记录引用时，保留登记。原始任务回传、备份和审计可继续访问。旧候选能量缓存失效后重建，不按几何hash永久封禁；以后可重新搜索、登记和计算同一结构。

恢复使用现有`apply_quality_review(...decision='restore',human_requested=True)`及`commit_human_quality_review`，校验备份、当前模型/边界和文件哈希。人工恢复后，同模型同记录同几何不立即重复删除，原审计保留。

每轮完整Relax/MC导入后自动诊断并发布对照图与简版Markdown；JSON保留计算细节。验证使用最小合成数据和自动清理临时目录，真实Co只读。不操作服务生命周期。
