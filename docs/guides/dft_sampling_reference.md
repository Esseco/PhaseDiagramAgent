# DFT选点参考

目标是先获得可靠相图，再兼顾模型改进。agent结合当前证据调整取舍；不增加自动评分、固定权重/比例或D硬阈值。共用参考来自 `dft_sampling_reference()`，由现有选点请求传入，无额外模型调用。

| 证据组合 | 默认考虑 |
| --- | --- |
| 当前近凸包，H高 | 优先验证决定凸包的结构，即使QBC低 |
| D、QBC都高 | 核查疑似低能失准，选同簇代表，不重复计权 |
| D高、QBC低 | 保留共同偏差抽检；委员会一致仍可能共同偏低 |
| QBC高、D不突出 | 改善模型，优先近凸包和缺少DFT覆盖的环境 |
| 原始Ehull高、递归后近凸包 | 保留条件候选，说明需要先移除哪些结构 |
| 三者均不突出 | 看已有DFT覆盖，决定补充、少量抽检或延期 |

同组分同相的同一疑似低能簇，默认先选一个代表；缺少可靠DFT基准时，再考虑一个上方参考。优先利用已有结果，避免同簇近重复结构挤占名额。代表结合能量、局域环境和已有DFT选择，不强制只取最低点；若簇内差异或实测误差支持，可说明理由增加代表。上方参考来自绑定D证据中的参考簇，须有真实可用候选；缺失则报告。

可靠基准指同组分同相、DFT计算设置和能量口径可比、已完成且质量合格的结果；直接验证某个候选时，还须核对精确几何。同一几何已有有效DFT则复用。不能拿未完成任务、不可比能量或其他组分/相的结果冒充本簇基准。

agent可用已有 `post_dft_assessment` 和 `decision_feedback` 调整后续经验：若高D低QBC点实际误差大，提高共同偏差核查优先级；若高D簇得到DFT支持，减少同类重复核查。若误差大、排序不稳或覆盖有缺口，可有依据地拓宽Na/相/环境；近重复点收益低则转向未覆盖环境。每轮简述调整依据，没有实测结果就保持为假设。人工明确约束优先；这种调整不改D/H定义，不自动改cutoff、预算或删除规则，也不直接执行计算。

指标口径：

1. Ehull沿用实际保留集合的正式凸包及eV/atom单位；递归条件距离仅补充，不替换正式Ehull。
2. D_score是固定快照内同组分同相的小低能簇间隙/10，无量纲；低能候选集合最多5个结构，上方参考为紧邻单簇。大簇或参考不足留空。旧D_mev_per_O2只用于原审查规则。
3. H保留单点及D候选集合联合序列；最大值依赖已考察路径和前置移除假设，不能说成当前无条件影响。
4. QBC是已保存的委员会分歧；D/QBC任一突出即可提示核查，不能要求同时高。相关性不证明错误，低相关也不证明合理。
5. 缺失D/H/QBC表示未知，不填零，也不当作三者均低。所有已检查层都远离凸包的点，不因D大自动提权。

覆盖只在各相获准的Na域内评估，保护端点规则；样本比例不是热力学相含量。若候选池本身缺相/缺组分，应考虑补搜索，单靠选DFT不能补齐缺失结构。

沿用 `scientific_decision.selection_purposes`，逐结构标注 hull_verification/model_improvement/coverage/bias_check 之一，短reason保留现有长度限制。整批简述互补性、代表/参考的取舍、H前置假设、缺失项和经验调整依据。已排除结构继续走人工恢复接口；预算、输入准备、审批和执行沿用现有流程。

本参考只指导agent推理；不计算新指标、不提交DFT、不操作服务。新源码由用户下次手动启动加载。
