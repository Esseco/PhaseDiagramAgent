# Relax–MC 已冻结交付包的分区修订

默认 GPU 子任务使用 v100m3 与 v100g32。打包时固化调度配置和运行代码，因此更新源码后，既有压缩包仍使用原配置。

已准备且未提交的 BJ-HPC 包可通过项目 Agent 的离线入口 `CodexOffline.revise_unsent_relax_mc_delivery` 修订。调用前核对远端旧目录、作业记录和新目录冲突。入口接收 bundle_id、原 inputs.zip 的完整 SHA256 和明确的 confirmed_unsubmitted=True，并检查项目任务均为原批次的待运行 Relax 任务。该字段记录调用者已核验的事实，入口本身不查询 Slurm。

入口为原科学计划生成单独的 *_GPUv2_input 目录，并登记原包哈希、新包哈希、分区和任务 ID。输入结构、模型、科学参数、任务 ID、原计划身份和本地结果回收路径保持一致。新交付包经本地校验后才登记，原包仍可用于审计。新包远端结果位于对应的 *_GPUv2_output 目录，回收时按原批次登记的本地结果路径交付。上传、提交仍按远端操作流程处理。
